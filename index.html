PROJECT_01 / FEATURED

Smart Dairy Milk Silo Data Pipeline

IoT Telemetry · Watermarked Incremental ETL · Quarantined Error Handling

AZ
Storage Event Trigger→ADF Lookup / Metadata / ForEach→Mapping Data Flows→ADLS Gen2 Parquet→Azure SQL Upsert
  • Engineered an event-driven ingestion and transformation pipeline for sensor telemetry across 5 dairy milk silos, structured around Bronze, Silver, and Gold zones on ADLS Gen2 plus a dedicated error quarantine layer.
  • Built SQL watermark-based incremental loading (Lookup, Get Metadata, Filter, ForEach, and stored procedures) so each run processes only newly arrived sensor payloads without reprocessing historical data.
  • Enforced schema/type casting, range validation, and deduplication by sample ID inside Mapping Data Flows, routing malformed records to an error sink for audit and replay while preventing pipeline failures.
  • Designed safe, repeatable reruns using idempotent upsert logic on sample ID into Azure SQL Database and automated cleanup of processed staging files.
Azure Data FactoryADLS Gen2Azure SQL DatabaseMapping Data FlowsSQL WatermarkingParquetJSON

WHY THIS DESIGN?

  • Parquet supports compressed, columnar analytical reads compared with raw CSV/JSON.
  • Watermarking limits repeated extraction; sample-ID upserts make retries repeatable.
